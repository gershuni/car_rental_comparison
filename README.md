# השוואת מחירי השכרת רכב שיתופי - סיטיקאר / מייקאר / מיטב

**🔗 לאתר: https://gershuni.github.io/car_rental_comparison/**

מחשבון להשוואת מחירי רכב שיתופי. מזינים משך השכרה (שעות או ימים) ומספר קילומטרים, והמחשבון מציג את המחיר לכל רכב ומסלול ומסמן את שלוש האפשרויות הזולות ביותר.

## מה נכלל

- **סיטיקאר** - מסלול שעתי (כולל מדרגות ותקרות ק"מ), יומי, שבועי וחודשי, לכל קטגוריות הרכב העיקריות.
- **מייקאר** - מסלול שעתי ויומי לרכב קטן, משפחתי ופיג'ו 5008.
- **מיטב** - רכב קטן, עד 5 שעות או יומי (משוער, כולל הערכת עלות דלק).
- **תוספת עונה** - לכל החברות.
- **מועדון סגול (סיטיקאר)**:
  - מחיר מקסימום לק"מ בתעריף השעתי לפי דרגה (מוביל / מאסטר).
  - הנחה על תוספת העונה (מוביל 20%, מאסטר עד 50%).
  - שדרוג רכב בסגולים - תשלום על הזמן כמו רכב קטן, עם הצגת עלות הסגולים ובדיקת יתרה.
- **הפחתת השתתפות עצמית** - תוספת לשעה/ליום לפי קטגוריה.
- **מבצעים** - ניתנים להפעלה דרך `promotionConfig` בקוד.

כל מחיר מוצג יחד עם הנוסחה שלפיה חושב (ריחוף עם העכבר מציג את הנוסחה המלאה).

## עדכון מחירים

כל האתר הוא קובץ אחד - `index.html`. המחירים מרוכזים בראש הסקריפט:

- `pricingConfig` - מחירי שעה/יום/שבוע/חודש, תוספות עונה, השתתפות עצמית ועלות שדרוג בסגולים לכל רכב.
- `CITYCAR_KM_TIERS` - מדרגות ותקרות הק"מ של סיטיקאר, כולל מחירי המקסימום למועדון.
- `CLUB_SEASON_DISCOUNT` - הנחת העונה לפי דרגת מועדון.
- `promotionConfig` - מבצע זמני (`isActive: false` לכיבוי).

מקור המחירים: [מחירון סיטיקאר](https://www.citycar.co.il/price_list_screen), [מועדון סגול](https://www.citycar.co.il/about_points_club_screen). המחירים הם להערכה בלבד - יש לוודא מול החברה לפני הזמנה.
